# MegaCD MiSTer — Complete Audio Signal Path Analysis

## Overview

The audio path spans 3 clock domains and 6 processing stages. Audio is generated by 4 independent sources, mixed in stages, optionally compressed, then crosses from `clk_sys` (~53.7 MHz) to `clk_audio` (24.576 MHz) before final filtering and output.

---

## Stage 1: Audio Source Generation (all in `clk_sys` domain)

### 1A. YM2612 FM Synthesis (`rtl/GEN/jt12/`)
- 6-channel, 4-operator FM synthesizer (Yamaha YM2612 clone by Jose Tejada)
- Outputs: `FM_left[15:0]`, `FM_right[15:0]` (signed)
- `EN_HIFI_PCM` (`status[23]`) enables interpolated PCM playback mode within the YM2612
- Controlled by the main 68000 CPU via memory-mapped registers

### 1B. PSG (`rtl/GEN/jt89/`)
- SN76489-compatible programmable sound generator (4 channels: 3 tone + 1 noise)
- Output: `PSG_SND[10:0]` (signed)
- Controlled by the Z80 sound CPU

### 1C. PCM (`rtl/MCD/PCM.vhd`)
- Ricoh RF5C164 — 8-channel PCM sample player
- Each channel has: envelope (ENV, 8-bit), panning (PAN, 4-bit L + 4-bit R), frequency (FD, 16-bit), loop start (LS), start address (ST)
- Sample rate: derived via `CEGen` at ~32.5 kHz per channel (12.5 MHz / 384 = 32552 Hz, ×8 channels ×2 steps = 520832 clocks)
- Per-channel processing:
  - 8-bit unsigned waveform read from 64KB wave RAM (`PCM_RAM`, dual-port)
  - Bit 7 = sign, bits 6:0 = magnitude
  - `WD[6:0] × ENV[7:0]` → 16-bit intermediate
  - `× PAN_L[3:0]` / `× PAN_R[3:0]` → 19-bit per side
  - Accumulated across all 8 channels with saturation clamping (`CLAMP16`)
- Outputs: `PCM_SL[15:0]`, `PCM_SR[15:0]` (signed)

### 1D. CD-DA (`rtl/MCD/CDDA.vhd` — entity `CD_DAC`)
- CD Digital Audio — 16-bit 44.1 kHz stereo PCM from disc image
- Data arrives from HPS via `CDC_DATA[15:0]` with `CDC_CDDA_WR` strobe
- Written into a **CDDA_FIFO** (`rtl/MCD/CDDA_FIFO.v`):
  - 5KB circular buffer (5×1024×8/32 = 1280 entries of 32 bits)
  - `WRITE_READY` goes high when buffer can accept another 2352-byte CD sector
  - Pairs of 16-bit L/R writes are assembled into 32-bit words before FIFO push
- Read side clocked by `SAMPLE_CE` at ~44.1 kHz (via `CEGen`: PAL=532034/441, NTSC=536931/441)
- **Fader/Attenuator**: 11-bit attenuation register `ATT` written by ASIC's `FD_DAT` signal
  - `ATT_CUR` ramps toward `ATT` by ±1 per sample (smooth volume transitions)
  - Output = `sample × ATT_CUR >> 10`
- Outputs: `CDDA_SL[15:0]`, `CDDA_SR[15:0]` (signed)

## Stage 2: Genesis Internal Mixing (`rtl/GEN/gen.sv`)

Inside `gen.sv`, FM and PSG are processed before mixing:

1. **FM amplitude adjustment**: scaled by ~19.25× (`<<4 + <<2 + <<1 + >>>2`)
2. **Optional FM low-pass filter** (`genesis_fm_lpf`): 2nd-order IIR, applied when `LPF_MODE == 2'b01`
3. **PSG adjustment**: `PSG_SND - (PSG_SND >>> 5)` (~0.969× slight attenuation)
4. **Mixing** in `jt12_genmix`: FM (if `ENABLE_FM`) + PSG×8 (if `ENABLE_PSG`), with rate conversion/interpolation
5. **External audio blend** (`EXT_EN` = `status[27]`):
   - If `EXT_EN=0`: `output = genesis>>1 + ext>>1` (both halved, then summed)
   - If `EXT_EN=1`: `output = genesis` (full level, no external mix — MCD audio handled separately outside)
6. **Final genesis LPF** (`genesis_lpf`), mode selected by `LPF_MODE[1:0]`:

   | Mode | Filter | Cutoff |
   |------|--------|--------|
   | `00` | Model 1 Genesis | ~3.1 kHz |
   | `01` | Model 2 Genesis | ~3.96 kHz |
   | `10` | Minimal | ~8.5 kHz |
   | `11` | Bypass | none |

- Output: `GEN_AUDL[15:0]`, `GEN_AUDR[15:0]` (signed) → `DAC_LDATA/DAC_RDATA` ports of gen module

## Stage 3: Top-Level MCD + Genesis Mixing (`MegaCD.sv:829-850`)

All in `clk_sys` domain:

```verilog
// MCD sources: each halved (>>1), masked by enable flags
mcd_l <= (EN_MCD_PCM ? PCM_SL>>>1 : 0) + (EN_MCD_CDDA ? CDDA_SL>>>1 : 0);
mcd_r <= (EN_MCD_PCM ? PCM_SR>>>1 : 0) + (EN_MCD_CDDA ? CDDA_SR>>>1 : 0);

// Final mix depends on status[27]:
if (~status[27]):  // Normal MCD mode
    aud_l <= GEN_AUDL>>>1 + mcd_l>>>1;   // Both halved again (-12dB total vs raw)
    aud_r <= GEN_AUDR>>>1 + mcd_r>>>1;
else:              // Genesis-only mode
    aud_l <= GEN_AUDL;                     // Full level
    aud_r <= GEN_AUDR;
```

Note: `status[27]` serves double duty — it also controls `EXT_EN` inside `gen.sv` (line 633). When `status[27]=0`, genesis mixes MCD audio both internally (via `EXT_SL/SR` in gen.sv) AND externally here. When `status[27]=1`, it's Genesis-only at full volume.

**Enable flags** (active when corresponding status bit is 0, OR debug menu is off):
- `EN_GEN_FM` = `~status[11] | ~dbg_menu`
- `EN_GEN_PSG` = `~status[12] | ~dbg_menu`
- `EN_MCD_PCM` = `~status[25] | ~dbg_menu`
- `EN_MCD_CDDA` = `~status[26] | ~dbg_menu`

## Stage 4: Dynamic Range Compression (`MegaCD.sv:808-850`)

Optional compressor with two presets controlled by `status[58:57]`:

```verilog
// Two compressor curves, selected by status[58]:
// Preset 1 (status[58]=0): f=4, a=2 — moderate compression
// Preset 2 (status[58]=1): f=8, a=4 — heavy compression

compr(inp):
    v = abs(inp)
    if (v < threshold): output = v × gain        // linear region
    else:               output = (v-threshold)/factor + knee  // compressed region
    restore sign
```

Final output selection:
```verilog
AUDIO_L = status[58:57] ? compr(aud_l) : aud_l;  // compression if either bit set
AUDIO_R = status[58:57] ? compr(aud_r) : aud_r;
```

---

## Stage 5: Clock Domain Crossing (`sys/audio_out.v:316-416`)

`AUDIO_L/R` from `clk_sys` → `clk_audio` (24.576 MHz) via `audio_cdc_fifo`:

- **4-entry async FIFO** with gray-coded pointers
- 32-bit wide (L+R packed)
- Write side (`clk_core`): writes every cycle, advances pointer when not full
- Read side (`clk_rd`): captures latest sample when not empty
- `(* ramstyle = "logic" *)` forces register-based storage (no block RAM for 128 bits)
- Two-stage synchronizers on both pointer directions for metastability protection

This is the **new CDC mechanism** on the `audio_cdc` branch, replacing the previous dual-register stability check.

---

## Stage 6: Audio Output Processing (`sys/audio_out.v`, `clk_audio` domain)

After CDC, the signal passes through 4 sub-stages:

### 6A. IIR Filter
- Configurable coefficients passed from `sys_top.v` (via `hps_io` from Linux side)
- `flt_rate` controls the filter update rate
- `cx/cx0/cx1/cx2/cy0/cy1/cy2` are user-configurable filter coefficients
- `is_signed` handles signed/unsigned conversion
- Output: `acl[15:0]`, `acr[15:0]`

### 6B. DC Blocker
- `DC_blocker` module removes DC offset from filtered signal
- Has mute control during startup (delayed enable via `a_en2`)
- Output: `adl[15:0]`, `adr[15:0]`

### 6C. ALSA + Stereo Mix (`aud_mix_top`)
- Mixes core audio with Linux ALSA audio (`alsa_l/r` from HPS SPI interface)
- **Stereo crossfeed** (`mix` parameter, 2 bits):

  | mix | Behavior |
  |-----|----------|
  | 0 | No crossfeed (stereo) |
  | 1 | 12.5% opposite channel |
  | 2 | 25% opposite channel |
  | 3 | 50/50 mono |

- **Attenuation** (`att[4:0]`): bit 4 = mute, bits 3:0 = right-shift amount (0-15 = 0 to -90dB)
- Output clamped to prevent overflow

### 6D. Physical Outputs (all from `clk_audio`)
- **I2S** → HDMI audio (HDMI_SCLK, HDMI_LRCLK, HDMI_I2S)
- **SPDIF** → optical/coax digital out
- **Sigma-Delta DAC** → analog audio jacks (1-bit PDM, directly on FPGA pins)
- HDMI_MCLK = `clk_audio` (24.576 MHz master clock)

## Gain Budget Summary

| Stage | Left/Right Gain | Cumulative |
|-------|----------------|------------|
| YM2612 raw | ×19.25 | ×19.25 |
| PSG raw | ×0.969, then ×8 in mixer | ×7.75 |
| gen_lpf | ×1 (filter, no gain) | same |
| MCD PCM/CDDA | >>>1 (×0.5) | ×0.5 of source |
| MCD → top-level mix | >>>1 again (×0.25 total) | ×0.25 of source |
| Genesis → top-level mix | >>>1 (×0.5) | ×0.5 of gen_lpf output |
| Compressor | variable (up to ×4 linear gain for quiet signals) | depends on level |
| aud_mix_top att | >>>att[3:0] | ×2^(-att) |
